Problème : Obsolescence programmée

Quand Windows 10 ne sera plus supporté, des milliers d'ordinateurs fonctionnels risquent la poubelle...

✅ Solution NIRD : Linux

  • 🐧 Installer Linux : Distributions légères comme Ubuntu, Linux Mint ou Debian donnent une seconde vie aux vieux PC
  • ♻️ Réduire les déchets : Un PC de 10 ans peut fonctionner parfaitement avec Linux
  • 💰 Économiser : Pas de licence à acheter, tout est gratuit
  • 🎓 Projet pédagogique : Le lycée Carnot a sauvé tout son parc informatique !
📥 Télécharger Ubuntu →

Problème : Données hors UE

Les données scolaires sont souvent hébergées aux États-Unis, posant des questions de souveraineté...

✅ Solution NIRD : Hébergement local

  • 🏫 Serveur dans l'établissement : Nextcloud pour le stockage et la collaboration
  • 🇫🇷 Clouds souverains : Apps.education.fr hébergé en France
  • 📧 Messagerie locale : Serveurs mail auto-hébergés
  • 🛡️ Contrôle total : Vous gardez la main sur vos données
🌐 Découvrir Nextcloud →
🔓

Problème : Écosystèmes fermés

Difficile de changer de solution quand tout est verrouillé dans un seul écosystème...

✅ Solution NIRD : Standards ouverts

  • 📄 Formats libres : ODF (OpenDocument) au lieu de .docx propriétaire
  • 🔄 Interopérabilité : Les logiciels libres communiquent entre eux
  • 🚪 Pas de prison dorée : Changez d'outil quand vous voulez
  • 🌍 Communauté mondiale : Des millions de développeurs contribuent
🎯

Par où commencer ?

🚀 Plan d'action progressif

Étape 1 - Sensibilisation (1 mois)
Organiser une réunion d'information, montrer des vidéos du lycée Carnot, tester Linux en live USB
Étape 2 - Expérimentation (3 mois)
Installer Linux sur quelques postes pilotes, former une équipe volontaire, documenter l'expérience
Étape 3 - Déploiement (6-12 mois)
Migration progressive, formation des utilisateurs, mise en place du support technique
Étape 4 - Autonomie (continu)
Partager votre expérience, contribuer à la communauté NIRD, inspirer d'autres établissements
